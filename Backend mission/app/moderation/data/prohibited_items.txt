# 华立转角 · 校园平台禁售清单
#
# 格式：词条|分类|级别|处置
#   级别：高 = 法定禁止流通，一律拦截
#         中 = 平台限制（校园场景卫生/安全/资质），允许发布但送人工审核
#   处置：block = 拦截发布  review = 允许发布但打标进待审队列
#
# 匹配是「整串包含」，所以**不要收单字**。
# 只收「匕首」「弹簧刀」，不收「刀」——否则「剪刀」「水果刀」「《刀锋》」全中招。
#
# 维护约定：每条都要能说清依据（法定禁止 / 校园卫生与安全 / 平台规则）。
# 本清单是**平台自建**：开源社区没有现成的电商禁售品目录，
# 已有的开源词库都是暴恐·政治·色情·非法网址，与本清单不是一回事。
# 依据与调研结论见 docs/管理端权限清单-v2.md。
