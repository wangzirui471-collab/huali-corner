# 华立转角 · 交易外流（反引流）规则
#
# 格式：词条|分类|级别|处置
#   级别：高 = 明确的把交易移出平台的指令，拦截
#         中 = 疑似，允许发布但打标
#         低 = 仅记录，不打扰用户
#   处置：block = 拦截  review = 打标待审  report = 仅记录
#
# 为什么自建而不用开源黑名单：
# 开源网址黑名单（如 fwwdn/sensitive-stop-words 的「网址.txt」14594 条）收录的是
# 赌博·色情小站域名，而本站学生真正的外流目标是闲鱼、转转、微信、QQ，
# 两者交集几乎为零，直接用等于没装。详见 docs/管理端权限清单-v2.md。
#
# 重要：「当面交易」「线下交付」在本站是**正常且被鼓励**的（同一个校区）。
# 要拦的是「把交易移出平台收款」，不是「线下见面」。所以只收明确的外流指令。
