# 华立转角 · 微信小程序（体验版）

## 现在能不能用？

代码是完整的（首页 / 商品详情 / 发布 / 我的 / 订单 / 社区 / 消息 / 客服），但**没有发布**，微信里搜不到。

目前走「**体验版**」：指定同学扫码就能用，**不需要审核**，也就不受「二手交易」电商类目的资质限制。

## 前提

1. 一个**真实小程序 AppID**（微信公众平台注册个人主体，免费，需身份证 + 人脸）
2. 一台跑后端的电脑，与手机在**同一局域网**
3. 微信开发者工具（稳定版）

## 一、拿到 AppID

1. 打开 <https://mp.weixin.qq.com> → 注册 → 小程序 → 个人主体
2. 注册完成后在「开发管理 → 开发设置」里复制 AppID
3. 填进本目录 `project.config.json` 的 `"appid"`（替换 `touristappid`）

## 二、启动后端（让手机能连）

```bash
cd "Backend mission"
python server.py --host 0.0.0.0 --port 8080            # 演示模式（验证码登录）
python server.py --host 0.0.0.0 --port 8080 --trial    # 试用版（手机号+密码登录）
```

- `--host 0.0.0.0` 必须加，默认只绑定 127.0.0.1，手机连不到。
- 查电脑局域网 IP：命令行执行 `ipconfig`，找「IPv4 地址」，例如 `192.168.1.5`。
- Windows 防火墙需要放行 8080（首次启动一般会弹窗，选「允许」）。
- 校园 WiFi 常做客户端隔离（设备之间不通），连不上时**用手机开热点给电脑**最稳。

## 三、开发者工具导入 + 本地预览

1. 微信开发者工具 → 导入项目 → 目录选 `web 7M/miniprogram`
2. AppID 用你的真实 AppID（或测试号）
3. 右上角「详情 → 本地设置」勾选 **不校验合法域名、web-view、TLS 与 HTTPS 证书**
4. 点「编译」，模拟器里即可点击浏览

## 四、设置后端地址（不用改代码）

小程序内进入「我的」页，底部有：

```
后端：http://127.0.0.1:8080
[设置后端地址]
```

点它填电脑的局域网地址（如 `http://192.168.1.5:8080`），保存后立即生效、重启保留。
默认的 `127.0.0.1:8080` 只在电脑模拟器里有效，**手机上 127.0.0.1 指向手机自己**。

也可以直接改 `config.js` 的 `baseURL`（改代码需重新上传）。

## 五、上传体验版

1. 开发者工具右上角「上传」，版本号填 `1.0.0`
2. 打开公众平台 → 管理 → **版本管理** → 开发版本 → 找到刚上传的版本 → **设为体验版**
3. 公众平台 → 管理 → **成员管理** → 体验成员 → 添加同学的微信号
   （体验成员有人数上限，以后台显示为准）

## 六、同学怎么用

1. 你（管理员）在版本管理页获取**体验版二维码**，发给同学
2. 同学微信扫码 → 进入小程序
3. **第一次进入必须开调试**：右上角「…」→「打开调试」→ 重新进入
   （否则微信会做域名校验，HTTP + 局域网地址会被拦为「不合法的域名」）
4. 之后在「我的」页确认后端地址正确，即可登录使用

> 想让同学**不用开调试**也能用，就必须把后端部署到 **已备案的 HTTPS 域名**，并在公众平台配置 request 合法域名。这是正式版的门槛，体验阶段可以不碰。

## 已知限制

- 高级客服工作台、信誉处罚、群管理员审批、完整备份与资金对账**以网页为主**，小程序只覆盖基础流程。
- 小程序与网页共用同一个后端和数据（试用版数据在 `var-trial/`），不是独立假数据。
- **正式发布**需要：微信认证 + 已备案 HTTPS 域名 + 电商类目资质。个人主体基本过不了二手交易类目，所以不要指望公开上架。
- 手机端真机预览依赖局域网稳定性，演示时建议提前连好热点并试跑一遍。
