# 原生微信客户端

导入此目录到微信开发者工具，开发AppID请自行填写。默认API为电脑本地8080端口。开发者工具可能需允许本地非合法域名；正式版必须使用符合微信要求的HTTPS服务和域名，不能延用本地测试设置。

先运行项目根目录的 `python3 server.py`。首页 → 我的 → 测试账号登录；发布页需要实际上传三张不同角度图片。数据、消息和订单来自同一个后端，无独立假数据源。

本地模拟OTP和资金逻辑绝不可直接公开；当前后端仅绑定回环地址，手机真机不能直接访问电脑回环地址。本次没有微信开发者工具或真实AppID，因此没有完成WXML/WXSS编译、真机联调和微信审核，不能称已发布小程序。

高级客服工作台、信誉处罚、群管理员审批、完整备份与资金对账以网页为主。小程序可执行基础工单反馈、客服处理、私聊群聊和订单流程。
