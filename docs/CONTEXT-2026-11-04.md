## 4. 桌宠「放大 / 缩小」的 bug（本次修复，保留）

三个看起来无关的现象，根因其实只有一处。这一节按「现象 → 根因 → 改法 → 验证」记。

### 4.1 三个用户能看见的症状

| 症状 | 触发方式 |
| --- | --- |
| 桌宠放大后右半身被屏幕右边裁掉 | 设置 → 外观 → 大小拖到 140% / 160% |
| 气泡被压成一字一行、还溢出屏幕 | 桌宠停在右下角时，出现「早安，今天有要出的闲置吗？」 |
| 对话面板「放大 → 还原」后位置跳走、高度变高 | 点标题栏右上角的放大按钮再点还原 |

### 4.2 实测数据（Playwright，1440×900，量 `#ai-pet-body` 包围盒）

| 档位 | 改前 | 改后 |
| --- | --- | --- |
| 100% | x=1338 w=82 → 右边界 1420（距屏幕 20px） | 不变 |
| 140% | x 仍是 1338，右边界 **1452（出屏 12px）** | x=1322，右边界 1436（留 4px） |
| 160% | 右边界 **1469（出屏 29px）** | x=1305，右边界 1436（留 4px） |
| 60% | 位置不动，右下留 53px 空隙 | 以底边中点收拢到 x=1346 |

面板：默认 `(1056,392) 372×288` 放大再还原，改前变 `(1056,360) 372×320`（上移 32、长高 32）；
用户拖过尺寸时 `(843,348) 585×541` 还原后跑到 `(843,139)`。改后两种情况都能精确回原样。

### 4.3 根因（一处设计 + 两处实现）

1. **桌宠的 `left/top` 是左上角坐标**。`applySkin()` 只改了 `--pet-s`（尺寸），没有重新夹回视口，
   所以放大时只朝右下方向长，右边先出屏。
2. **气泡的包含块就是桌宠本身（82px 宽）**。`.ai-pet-reaction` 是绝对定位子元素，
   自动宽度按「到包含块右边还剩多少」算，可用宽度只剩 41px，浏览器只能一字一行地折。
3. **`setPanelMax()` 只记住了尺寸，没记住位置**。还原时 `placePanel()` 按桌宠重新贴一次，位置自然变了。

附带发现：首次访问的提示条（「点我聊天 · 长按摸摸 · 拖动换位置」）和 1.2 秒后的问候气泡
贴在同一个位置，叠在一起两条都读不清。

### 4.4 改法（两个文件）

| 文件 | 改动 |
| --- | --- |
| `src/components/ai-pet.js` 新增 `reanchor(prev)` | 尺寸变化前后各量一次盒子，以**底边中点**为锚点重新贴位，再走 `moveTo()` 的夹取；顺带 `savePos()` + `placePanel()` + `fitBubble()` |
| 新增 `fitFloating(el, varName)` | 量气泡/提示条的 `offsetWidth`（布局宽度，不受 `transform: scale()` 影响），算出水平补偿写进 `--bubble-dx` / `--hint-dx` |
| `setPanelMax()` | 连 `left/top` 一起记；没拖过尺寸就记 0，还原交给 CSS 自然高度 |
| `mountPet()` | 首访时把问候延到提示条收起之后（7 秒） |
| `ai-pet.css` | 气泡 / 提示条改 `width:max-content; max-width:min(200/260px, 100vw-32px)`，去掉 `white-space:nowrap`，位置改 `left: calc(50% + var(--…-dx))`，尖角跟着补偿量回指桌宠 |

### 4.5 验证

| 项 | 结果 |
| --- | --- |
| 四个缩放档位复测 | 右边界最大 1436，不再出屏 |
| 面板放大 / 还原 | 尺寸和位置与放大前完全一致；窗口 720×560 ↔ 1440×900 来回也不丢 |
| 气泡 | 100% / 160% / 390 宽下都是横排、完整可见 |
| 首访 | 0.9s 只出现提示条，7s 后提示收起才出问候 |

## 5. 逛逛页 v3（最终采用）

这一节记录设计决策与令牌位置，方便以后改配色或整个退回旧版。

### 5.1 为什么改

用户给了一张参考图（白底 + 墨绿 + 陶土橙、单通栏主视觉、频道页签、四列无边框商品卡、
底部发布带），指出当前首页「太丑」。上一版（`34e894b` 之后）是七块彩色磁贴 + 两张渐变卡，
颜色杂、层级散。

### 5.2 设计系统（要改配色只改这一处）

`web 7M/home.css` 顶部：

```css
.home-page,
.market-header-home {
  --ho-ink: #1e3a33;      /* 主墨色：标题、主按钮 */
  --ho-ink-2: #3f5c53;    /* 次级文字 */
  --ho-mute: #7d8f87;     /* 说明文字 */
  --ho-faint: #a3b3ab;    /* 计数、占位 */
  --ho-line: #e6e9e1;     /* 分割线 */
  --ho-canvas: #faf9f6;   /* 画布：暖白 */
  --ho-mint: #dcece1;     /* 主视觉 / CTA 底色 */
  --ho-mint-2: #eef5ef;   /* 悬停底色 */
  --ho-accent: #eb754d;   /* 陶土橙：CTA、选中下划线 */
  --ho-price: #dd3f2b;    /* 价格红 */
}
```

**全站令牌（`market.css :root`）一个都没动**，社区、论坛、详情、订单、后台仍是原来的品牌黄。
要换回黄主题，改这十个值即可；要全站统一，另开一轮。

### 5.3 结构对比

| 区块 | 旧版 | v3 |
| --- | --- | --- |
| 顺序 | 频道磁贴 → 主视觉 → 商品流 | **主视觉 → 频道页签 → 转角发现 → 商品流 → CTA** |
| 页头 | 品牌黄、小转 AI 暗夜霓虹 | 白底 + 墨绿；搜索键陶土橙，小转 AI 改浅薄荷，校区说明移到提示条左侧 |
| 频道 | 7 块 56px 彩色磁贴 | 7 个页签（线性图标 + 文字），选中项薄荷底；≤580 折成四列两行 |
| 标题区 | kicker + 25px 标题 + 单独一行计数 | 「转角发现」+ 说明与计数同行；右侧「最新上架 / 价格 / 筛选」纯文字 + 橙色短横线 |
| 商品卡 | 有边框有阴影 | 去边框，图 1:1 圆角 16，价格红、地点带定位、卖家行细分割线 |
| 底部 | 三段渐变卡 | 薄荷通栏 + 英文眉 + 大标题 + 橙色按钮 + 线稿纸箱 |
| 收藏页 | 「我的收藏」+「收藏好物」两个标题 | 只留一个 `h1 我的收藏` |

### 5.4 响应式

| 宽度 | 结果 |
| --- | --- |
| ≥1500 | 5 列商品 |
| 1440 | 4 列，双卡主视觉，7 个频道一排 |
| 1180 | 3 列，主视觉插画收窄 |
| 850 | 2 列，主视觉改单列 |
| 580 / 390 / 320 | 头部两行（品牌+动作 / 搜索）、频道四列两行、筛选独占一行、CTA 竖排按钮满宽 |

实测 1440 / 768 / 390 / 320 四个宽度 `scrollWidth - innerWidth = 0`，无横向溢出。

### 5.5 删除的东西

| 文件 / 符号 | 原因 |
| --- | --- |
| `src/components/category-art.js` | 唯一调用方是旧频道磁贴；对应 `modulepreload` 一并去掉 |
