# 本机账号降为普通用户

本工具供能够操作服务器数据目录的运营者使用，只能将平台管理员或客服降为普通用户，不提供网页接口，也不提升任何账号权限。

云端开发环境没有 godfly 的实际账号；生成、下载工具或同步代码不会改变你电脑上的账号。必须在运行网站的那台电脑，对现用数据库运行工具。

## Windows 使用

1. 在运行网站的终端按 `Ctrl+C` 停止服务。
2. 将工具压缩包完整解压，双击 `将godfly降为普通用户.bat`。
3. 在弹窗选择现用项目根目录，或其中保存 `market.sqlite3` 的 `var-trial` 目录。自定义数据目录请选择实际目录，不要选择下载的旧副本。
4. 看到“godfly 已降为普通用户”后，关闭工具，按原来的方式启动网站。godfly 需要重新登录。

工具使用 Python 标准库，无需安装额外依赖。若没有图形目录选择器，会提示在终端输入数据目录。Windows 双击启动和弹窗仍需在用户本机验证；命令行与便携包已用临时数据库测试。

## 修改范围

- 更新指定账号的平台角色为 `user`，保留账号状态、密码、信誉、商品、订单和社区成员关系。
- 撤销该账号旧登录会话，重新登录后使用普通用户权限，仍可下架自己的商品。
- 将分配给该账号的未结工单退回未分配队列；处理中变为待处理，复核状态保留，已结束工单保留历史。
- 修改前在现用数据目录的 `backups/` 创建 SQLite 一致性备份；事务中记录审计，失败时回滚修改。

备份包含账号数据，仅在服务器本机保管，不要上传到 GitHub 或公开发送。

## 命令行与拒绝操作的情况

从仓库根目录运行：

```powershell
python scripts/demote_staff.py --data "E:\现用项目\var-trial" --nickname godfly
```

便携包解压目录下运行时，将 `scripts/demote_staff.py` 改为 `demote_staff.py`。

昵称匹配不区分英文大小写。遇到同名账号时不会批量修改，需核对账号 ID 后加 `--user-id 123`；ID 必须与昵称同时匹配。找不到账号、数据库格式不支持、选中了演示库或目标为最后一个启用的管理员时，工具拒绝操作，不会创建新账号或初始化数据库。目标已经是普通用户时重复运行不再改动。

## 维护位置与验证

- 业务操作：`Backend mission/app/staff/roles.py`
- 本机入口：`scripts/demote_staff.py`
- 回归验证：`python -m unittest discover -s tests -p test_operator_demotion.py -v`

不要将脚本接为公开 HTTP 接口；不要在启动网站时自动执行。生成便携包时，将入口脚本与业务文件分别复制为 `demote_staff.py`、`roles.py`，只携带代码和说明，不携带数据库。
