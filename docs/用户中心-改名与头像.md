# 用户中心：改名与头像

2026-10-17 接入。来源是 `archive/feat/user-center`（即 PR #1 的 U01–U03）——
那份代码当时只写了领域层，**从未接到 HTTP 路由**（见原分支
`docs/modules/user-center/INTEGRATION.md` 的「未注册新的 HTTP 路由」）。这次是把它接进
主分支的现有结构，不是整包合并。

## 接口

| 方法 | 路径 | 作用 | 失败码 |
| --- | --- | --- | --- |
| GET | `/api/user/profile` | 读自己的资料（含 `profile_version`、`avatar_url`） | 401 |
| POST | `/api/user/profile` | 改资料，白名单 `nickname/major/bio/degree_level/study_status/profile_version` | 400 字段越界 · 409 版本过期 |
| POST | `/api/user/avatar/upload` | 上传头像，body 只允许 `{content}`（base64） | 400 非图 · 413 过大 |
| POST | `/api/user/avatar` | 选定/移除头像，body 只允许 `{upload_id,profile_version}` | 403 非本人 · 404 文件缺失 · 409 版本过期 |
| GET | `/media/ua_<32hex>` | 读头像。当前公开的任何人可读；未选中的只有本人可读 | 403 |

## 三条不能松的规则

1. **头像不进旧 `uploads` 表。** 那张表里还有订单凭证等私密图，混进去会让「选头像」
   变成一条扩大私密图权限的路。头像单独一张 `user_avatar_uploads` 表。
2. **`/media/ua_` 必须在通用 `/media/` 之前分流。** 头像不在旧表里，落到通用查询只会 404；
   授权完全在 `user_avatar_bytes()` 里判，外面不做第二次放行。
3. **改昵称也要带版本号。** 旧接口 `/api/me` POST 保留原样（老客户端与小程序还在用），
   但它内部走同一套适配器，每次保存都会递增 `profile_version`——否则旧页面存一次，
   新页面的并发保护就失效了。

## 图片处理

原文件 ≤2 MiB、真实解码为 JPEG/PNG/WebP、≤1600 万像素、拒绝动画与多帧；
EXIF 方向先校正，再重绘到最长边 512 的全新画布并转 WebP(85)。
**不复制原图的 EXIF/GPS/ICC**——手机拍的证件照常带定位。

## 数据迁移

`app/account/migrations.py` 给 `users` 补四列（`degree_level`、`study_status`、
`profile_version`、`avatar_upload_id`）并建头像表，在 `Store._init_schema()` 的
SQLite 分支里与其它补列跑在同一个事务中。只增不改：

- 只在**首次建列**时把旧 `education` 映射进新列（本科→bachelor、专科→junior_college、
  已毕业→study_status=graduated），之后不再回写。
- 只改昵称时保留原 `education`，不会把「本科」改写成「其他」。

## 前端

| 文件 | 作用 |
| --- | --- |
| `src/components/user-avatar.js` | 头像渲染；`avatar_url` 只认 `/media/ua_<32hex>`，外链与 `javascript:` 一律拒 |
| `src/components/user-profile.js` | 资料表单、头像表单、409 对照面板 |
| `src/actions/user-profile.js` | `user-*` 动作；上传前本地预览，确认后才公开 |
| `src/pages/me.js` | 自己的主页渲染表单；别人的主页保持只读 |
| `user-center.css` | 只在 `.user-center` 作用域内生效 |

`registerActions()` 里额外挂了两个监听：`change`（重选文件要让上一张的「确认」失效）
和捕获阶段的 `error`（`img` 的 error 不冒泡，用来把裂图退回默认头像）。
本地预览的 blob URL 登记在 `state.mediaURLs`，换页时由 `router.js` 统一 revoke。
