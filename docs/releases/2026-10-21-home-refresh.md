# 首页前端改版 · 2026-10-21

## 用户可见变化

- 首页按“搜索与快捷操作 → 单轮播专题 → 横向分类 → 图标入口 → 商品推荐”排列。
- 品牌使用暖黄，白底和中性灰，价格使用克制暖红；卡片统一大图、两行标题、价格、取货信息、卖家及收藏。
- 公共商品卡片不展示下架按钮；我发布的上下架、商品详情的既有管理能力、客服工作台处置继续保留。
- 商品每页 24 件，滚动追加并去重；加载失败保留原列表并显示重试按钮，也支持手动加载。
- 首页收藏就地更新，保留滚动位置；轮播支持上一张/下一张、专题按钮和暂停，悬停、聚焦、后台及减少动效偏好会暂停自动播放。
- 回到顶部、手机双列商品和九个快捷入口；保留逛逛、社区、论坛、我的、搜索、发布、求购、取货清单及消息。
- 公开演示导出带上新首页样式。

## 范围与兼容

沿用原生 ES modules、hash 路由、现有 API 和权限。未修改后端、数据库结构、真实账号、订单、上传图片或会话规则。

普通商品流使用既有 page/limit 接口。免费送和收藏保留原来的全量筛选语义，展示时分批追加；后续若增加专门的免费商品筛选接口，可进一步减少这两个场景的首个请求体积。

- 真实 Chrome：首页顺序、轮播切换/自动播放/暂停、分页失败重试、收藏位置、空搜索、免费送、旧请求隔离、收藏页、发布页、论坛及消息入口；390/320/768 像素无横向溢出；无 IntersectionObserver 时手动加载有效。
