## 当前采用的整理约束

- 后端保持 Python 与现有领域分层；正式入口为 `Backend mission/server.py`，领域组合根为 `app/market.py`。
- 路径统一来自 `app/core/config.py`；不修改两个带空格的主目录名。
- 保留所有原有账号、商品、图片、订单、工单和账务；测试使用独立临时目录。
- 保持现有 API 返回、ID 类型、整数分金额、角色权限和交易规则；不全仓格式化。
- 原始数据、环境文件、口令、备份和运行日志不得提交公共仓库。
- 修改相关模块时逐步改善命名、类型、注释与可读性；完成声明必须附实际验证。
