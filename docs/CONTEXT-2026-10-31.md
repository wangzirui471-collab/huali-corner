### 1.2 关键取舍

1. **岛只画界面，不做第二套业务。** 岛里的按钮一律写 `data-action` / `data-go`，
   仍由 `src/actions/index.js` 的文档级委托分发。取数、分页、收藏、筛选全在原生层，
   所以「完整功能保留」不是靠重写实现的，是靠没换实现实现的。
2. **只引 carousel 的按需样式。** 不引整套 `element-plus/dist/index.css`（362 KB），
   岛总共 44 KB gzip，且只在逛逛页加载；往岛里加组件要先看体积。
3. **必须有兜底。** 岛 import 失败或超 1.5 秒未到位，就用 `home.js` 渲染的原生轮播，
   同一套 `hc-*` class、外观一致。测试用 `window.HC_HOME_ISLAND=false` 强制走这条路，
   两条路径都在冒烟测试里。
4. **动态 import 的相对路径按模块解析。** 演示版挂子路径时 `./assets/...` 会指到
   `/src/assets/` 去，所以岛地址统一用 `new URL(path, document.baseURI)` 算绝对 URL。
5. **主题变量要挂到兄弟节点。** `.mobile-nav` 不在 `.market-app` 里，
   第一次改底栏颜色完全没生效（变量拿不到，整条声明被丢掉），
   现在令牌同时挂在 `.mobile-nav-home` 上，冒烟测试补了两条 computed style 断言。
