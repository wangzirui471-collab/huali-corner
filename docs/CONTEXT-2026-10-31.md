## 2. 这一版当时做了什么（回退前的实现记录，供下次参考）

- **入口去重**：原来「5 个分类频道 + 9 格快捷宫格 + 两个专题窗口」三排重叠，
  改成一条主视觉轮播（6 张专题合并）+ 一排 7 个频道 + 一条商品流，
  关键词快捷（台灯/收纳/球拍…）移进「筛选」弹窗。
- **主视觉用 Vue 3.5.44 + Element Plus 2.14.7 的岛**：源码 `home-ui/`，
  产物提交在 `web 7M/assets/home/`，与办公面板 `office-ui/` 同一套路；
  只引 carousel 的按需样式，岛 JS 137 KB（gzip 44 KB）+ CSS 12 KB，仅逛逛页加载。
- **岛只画界面**：按钮仍写 `data-action` / `data-go`，取数、分页、收藏、筛选、
  推荐轨全部留在原生层没重写——所以「完整功能保留」是靠没换实现做到的。
- **有兜底**：岛 import 失败或超 1.5 秒未到位就用原生轮播，同一套 `hc-*` class；
  测试用 `window.HC_HOME_ISLAND=false` 强制走兜底，两条路径都进冒烟测试。

### 两个坑（下次做岛还会遇到）

1. **动态 import 的相对路径按模块解析**：演示版挂子路径时 `./assets/...` 会指到
   `/src/assets/` 去，必须用 `new URL(path, document.baseURI)` 算绝对地址。
2. **主题变量要挂到兄弟节点**：`.mobile-nav` 不在 `.market-app` 里，
   变量拿不到会让整条覆盖声明被浏览器丢掉（表现是「改了没生效」），
   得给底栏单独加标记并把令牌挂上去。
