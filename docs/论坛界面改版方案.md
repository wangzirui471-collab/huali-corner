# 论坛界面改版方案（京东式干净专业风）

2026-10-21 · 评审对象：现有未提交的 forum 实现（`src/pages/forum.js`、`src/components/forum.js`、`src/actions/forum.js`、`forum.css`、`app/community/forum_read.py`）

**结论先说**：现有实现的**结构是对的**（三板块、列表/卡片、独立详情页、回复分页、折叠、内联编辑器都在），但它还是「把页面做完了」，没到「干净专业、值得信赖」的质感。方案不是推倒重来，是 **7 处结构性调整 + 一套排版尺度 + 移动端补齐**。

---

## 0. 现状盘点

| 需求项 | 现状 | 判定 |
| --- | --- | --- |
| 大面积白底 | `#f7f8fa` 画布 + `#fff` 卡片 | ✅ 达标 |
| 卡片简洁柔和 | 1px `#e7e9ed` 边框、10px 圆角、无阴影 | ✅ 达标 |
| 分区清晰 | 三板块卡 + 各带最新 2 帖 | ✅ 达标 |
| 列表/卡片切换 | `forum-layout` 双按钮，localStorage 记忆 | ✅ 达标 |
| 最新/热门排序 | `sort=latest` / `sort=hot`（按真实回复数） | ✅ 达标，但缺「筛选」 |
| 详情页楼层 | `details/summary` 折叠 + 楼号 | ⚠️ 结构有，视觉不像卡片 |
| 回复分页 | `after` 游标、每页 20、可「从第一楼开始」 | ✅ 达标 |
| 阅读宽度 | `.forum-surface` 撑到 1200px，正文跟着变宽 | ❌ **长文难读** |
| 浏览数 | 后端 `posts` 表**没有 views 字段** | ❌ **无数据，不能编** |
| 置顶帖 | 后端**没有 pinned 字段**（`room_pins` 是聊天会话的，不是帖子） | ❌ **无数据，不能编** |
| 移动端 | `forum.css` **0 个 `@media`** | ❌ **硬伤** |
| 动效 | **0 个 `transition`**，悬停硬切 | ⚠️ 太生硬，需补但只补颜色 |
| 高饱和色 | 品牌黄 `#ffcc38` 仍出现在导航主按钮 | ⚠️ 与「减少高饱和」冲突 |
| 个人中心/消息 | 靠 `:has(.me-page)` 改背景，但页内仍是黄 pill 体系 | ⚠️ 与论坛视觉不统一 |

两条**不能糊弄**的：浏览量和置顶帖当前**没有真实数据**。任何「32 次浏览」「置顶」标签只要不是从库里读出来的，就是在骗用户——这两项要么加字段，要么不显示，见 §9.3。

## 1. 设计基线（改这 14 个值，全站观感就变了）

### 1.1 颜色

京东式的可信感来自「几乎无色的界面 + 一处克制的强调」，不是靠彩色分区。

| 令牌 | 现值 | 改为 | 理由 |
| --- | --- | --- | --- |
| `--f-ink` | `#252b34` | **`#1f2329`** | 标题更稳，接近印刷黑 |
| `--f-ink-2` | — | **`#3d4450`** | 正文主色，长文比纯黑柔和 |
| `--f-muted` | `#667085` | **`#6b7280`** | 元信息，与 `--ink-2` 拉开一档 |
| `--f-faint` | — | **`#98a0ad`** | 楼层号、分隔符等三级信息 |
| `--f-line` | `#e7e9ed` | **`#ebedf0`** | 更淡，减少「格子感」 |
| `--f-line-strong` | — | **`#dfe3e8`** | 只用于输入框与焦点边界 |
| `--f-bg` | `#f7f8fa` | **`#fafbfc`** | 画布更接近白，靠边框分区而不是靠灰底 |
| `--f-accent` | `#9b3e36`（砖红） | **`#4b5563`**（中性深灰） | 链接/标题 hover **不再变红**，改为变深 + 下划线 |
| `--f-action` | — | **`#2f3437`** | 主按钮：深灰实底，比品牌黄更「正规」 |
| `--f-danger` | — | `#c0392b` | 只给举报/删除，绝不做装饰 |

**品牌黄退出论坛区**：论坛内主按钮一律 `--f-action` 深灰；黄色最多保留在站点导航的「发布闲置」（回到交易区才出现），避免论坛页出现「电商促销感」。

### 1.2 排版

| 项 | 现值 | 改为 |
| --- | --- | --- |
| 基准字号 | 14px | **15px**（详情正文 16px） |
| 行高 | 1.65 | **1.75**；详情正文 **1.85** |
| 标题字重 | 700 | **650**（`font-weight:650`，比 700 轻、比 600 稳） |
| 列表标题 | 无固定字号 | **17px / 1.4**，两行内截断 |
| 摘要 | 不限高 | **2 行截断**（`-webkit-line-clamp:2`），行高 1.7 |
| 元信息 | 12px 混排 | **12.5px**，统一 `--f-muted`，数字 `font-variant-numeric: tabular-nums` |
| 段落间距 | `margin: .6em 0` | **`0 0 1.05em`**，详情正文段间 1.05em、行高 1.85 |
| 阅读列宽 | 随 1200px 容器 | **`max-width: 760px`**，居中；宽屏也不超过 78 个汉字/行 |

### 1.3 间距与圆角

- 圆角：**10px → 8px**（卡片）、输入框 6px、按钮 6px。更方一点更「专业」，也更接近京东。
- 卡片内边距：`24–26px → 20–24px`；列表行 `24/26 → 20/24`。
- 栅格间距：板块卡 `20px → 16px`；内容 + 侧栏 `24px → 28px`（内容更突出）。
- **列表不再一行一张卡**：同一板块内用「一张容器卡 + 分隔线」串起来，只在 hover 时给 2% 底色。这是京东商品列表的核心手法——减少边框数量。

### 1.4 动效

```css
transition: background-color .14s ease-out, border-color .14s ease-out, color .14s ease-out;
@media (prefers-reduced-motion: reduce){ .forum-surface *{ transition:none !important } }
```

- 只允许**颜色/边框/背景**过渡，**禁止** `transform`、`translate`、缩放、位移动画。
- 禁止 `animation` 关键帧（除非是无障碍的 `prefers-reduced-motion` 保护）。
- 悬浮不抬升、不加阴影扩散。

## 2. 论坛首页

**要解决的问题**：现在首页是「板块卡 + 最新讨论」两段平铺，缺少「站内导航 + 搜索」的第一层级，逛起来像落地页而不是论坛。

### 布局调整点

1. **双层导航收敛为一条**：现有 `shell()` 的站点导航（逛逛/社区/订单…）+ 论坛自己的 `forum-navigation`（论坛首页/求购/交换人生/代拿快递/我的帖子）叠成两条横条，很挤。改为：站点导航保留，论坛条改成**紧贴其下的轻量 tab**（下边框 1px，选中项 2px 深灰下划线），高度 48px，字号 14px，不再有底色块。
2. **搜索框进论坛头部**：复用顶栏搜索框但改 placeholder 为「搜索帖子、技能或需求」，并在论坛页把它**下沉到论坛 tab 同一行右侧**（PC）；移动端折叠成图标，点开全宽。
3. **板块区改为 3 列固定卡**（≥1024px）：每卡 = 图标（36px，线性，灰）+ 板块名（17px/650）+ 一句简介（13px muted）+ 2 条最新帖（15px，作者 12.5px 右对齐）+ 底部「浏览板块 →」。卡片高度对齐（`min-height:196px`），不因帖子条数跳动。
4. **最新讨论**：标题行「最新讨论 / 查看全部」，下面接**统一列表**（与列表页同一组件 `postRow`），显示 6 条。
5. **右侧栏**：「我的论坛」（我的帖子 / 回复与通知 / 个人中心）+「交流之前」（4 条规则）。侧栏卡片与主内容卡**同宽同边框**，宽 268px。
6. **不要**：板块彩色大图标、板块渐变背景、公告横幅滚动条。

## 3. 帖子列表页

**要解决的问题**：现在列表只有「最新/热门」两个按钮，没有筛选；行内信息靠 `·` 拼成一行，扫读时找不到重点。

### 布局调整点

1. **列表 / 卡片切换位置固定**：右上角图标切换（列表 `≡` / 卡片 `▦`），选中态只有底色变化，不做动画。记忆在 `localStorage`（已有）。
2. **排序 + 筛选合并成一条工具条**（列表页顶部，48px 高）：
   ```
   最新 │ 热门 │ 回复最多 │ 只看有回复        [≡|▦]
   ```
   左侧是**文字 tab**（不是彩色 pill），右侧是布局切换 + 结果计数「共 128 帖」。
3. **每条帖子的信息分层**（三行，最多三行）：
   - 第 1 行：`[置顶]` 标题（17px/650，两行内）+ 右侧 `回复 12`
   - 第 2 行：摘要（13.5px muted，**2 行截断**）
   - 第 3 行：板块 · 作者（12.5px 头像 + 名字）· 时间，全部 muted，`·` 分隔
4. **置顶标识轻量化**：不用彩色标签，改为行首 **2px × 18px 深灰竖线** + 12px 灰字「置顶」。视觉上「这一条被标记了」，不抢标题。
5. **行分隔**：同一容器卡内 `border-bottom:1px solid var(--f-line)`，最后一行去边框；hover 背景 `#fbfbfc`。
6. **加载更多**：底部居中文字按钮「加载更多帖子（还有 88 条）」，加载中显示「正在加载…」，到末尾显示细线 +「已经到底了」。
7. **卡片布局（切换后）**：2 列网格（≥1024px）/ 1 列（<1024px）；卡片 = 标题 + 摘要 3 行 + 底部作者行，`min-height:168px` 对齐。

## 4. 帖子详情页（重点）

**要解决的问题**：正文跟着 1200px 容器跑，长文一行 40+ 字，读到第三行就串行；回复是 `details` 但视觉像表格行，不像「独立轻卡片」。

### 布局调整点

1. **阅读列独立定宽**：内容区 `max-width: 760px` 居中，右侧留 268px 给目录/侧栏（≥1240px 才出现，否则单列居中）。**这是本方案最重要的一条**——长文可读性 90% 由行宽决定。
2. **楼主主帖做成「无边框头图区」**：
   - 面包屑（12.5px）→ 板块名（12.5px muted）→ 标题（26px/650，行高 1.35）→ 作者行（头像 36px + 昵称 15px/600 + 时间 12.5px muted + 「楼主」灰标签）
   - 作者行下一条 1px 分隔线，然后才是正文。**不要**把主帖包在重边框卡片里——首页已经有很多卡片了，主帖要靠留白区分。
3. **正文排版**：16px / 1.85 / `#3d4450`；段间 1.05em；`white-space: pre-wrap` 保留用户换行（现有行为，保留）；长词与 URL `overflow-wrap:anywhere`；引用块左侧 3px 淡灰竖条。
4. **楼层回复做成轻卡片**：
   - 每条 `background:#fff; border:1px solid var(--f-line); border-radius:8px; padding:16px 18px`，卡片间距 12px
   - 左侧固定 44px 序号列：`1F`（12.5px `--f-faint`，tabular-nums）
   - 作者行：头像 24px + 昵称 14px/600 + 时间 12.5px muted，右侧「回复」文字按钮
   - 正文 14.5px / 1.75，同上转义
   - 「回复 XX」引用行：12.5px，左侧 2px 竖线，`--f-faint`
   - **折叠**：每层卡片右上角一个 `⌄` 图标按钮（不是整行 summary），默认展开；>3 层回复或正文 >400 字时默认折叠，显示「展开全文」。保留 `details/summary` 语义以支持键盘。
5. **分页与「减少一次性卡顿」**：
   - 首屏只加载最新 20 条，顶部提示「共 47 条回复，正在显示最新 20 条」+「从第一楼开始阅读」
   - 底部「加载更早的回复」按钮；加载中显示 3 条骨架占位（灰条，无动画闪烁）
   - 回复框固定在内容流末尾，不做 sticky 浮层（避免遮挡阅读）
6. **回复框简洁**：一张卡片，`textarea`（无边框，只有下边线 1px）+ 底部一行「友善表达，保护彼此隐私。」+ 右侧主按钮「发布回复」（深灰）。引用某人时上方出现 12.5px「回复 阿哲 ×」的胶囊，可取消。
7. **右侧栏（≥1240px）**：作者卡（头像、昵称、发帖数、查看主页）+「本板块其他讨论」5 条。移动端全部下沉到文末。

## 5. 个人中心 / 消息页

## 7. 交互与动效规范

### 7.1 动效白名单

| 允许 | 禁止 |
| --- | --- |
| `transition` 颜色/边框/背景，140ms `ease-out` | `transform`、`translate`、缩放、位移 |
| 加载骨架的**静态**灰块 | 骨架闪烁动画、shimmer 扫光 |
| 折叠展开的即时切换 | 高度过渡动画（会引发回流卡顿） |
| 焦点环 `:focus-visible` 2px | 呼吸灯、脉冲、渐变流光 |

### 7.2 弹窗克制（现有实现已经不错，固化下来）

- **发帖/回复一律用页面内表单**，不用弹窗（现状已如此）。
- 只有三类允许弹：**举报**（需选原因）、**删除确认**、**登录**。
- 举报用二次确认的 `confirm` 风格小面板，不要整屏遮罩动画。
- 不允许「发帖成功」弹窗——改为页面顶部 2 秒的 inline 提示条。

### 7.3 键盘与读屏

- 论坛 tab 用 `<a href="#forum/xxx">` + `aria-current="page"`（现状已如此，保留）。
- 列表/卡片切换按钮保留 `aria-pressed`。
- 楼层折叠：`<details>` 原生语义，`<summary>` 内放作者行，屏幕阅读器可读「1F 王同学 1 小时前」。
- 空状态必须给下一步动作，不给纯插画（现在 `forumEmpty` 已有按钮，保留）。

## 8. 禁止项（写进 CSS 注释与评审清单）

1. **不要彩色标签铺屏**：板块/话题标签只用「灰字 + 1px 灰边框」，最多 1 个语义色（举报/删除）。
2. **不要表情包**：正文只渲染纯文本（现 `e()` 转义，保留），不接 emoji 资源。
3. **不要悬浮广告 / 侧边浮动客服**：侧栏是静态卡片，不 `position:fixed` 跟随。
4. **不要闪烁装饰**：禁止 `animation` 关键帧、禁止 `background-image` 渐变流光、禁止 `box-shadow` 呼吸。
5. **不要暗黑风**：全站单一日间主题，`--f-*` 无 dark 分支；不写 `prefers-color-scheme: dark` 覆盖。
6. **不要高饱和大面积填充**：品牌黄 `#ffcc38` 不得作为论坛区卡片/按钮/表头底色；仅允许小面积（≤24px 图标或 1px 线）。
7. **不要抬升阴影**：卡片允许 `0 1px 2px rgba(16,24,40,.04)` 仅用于「悬浮/可点」元素，其余无阴影。

评审方式：改完后 grep 一次 `forum.css` / 新增 CSS，确认无 `animation:`、无 `translate`、无 `#ffcc38` 大面积使用、无 `linear-gradient` 装饰。
