## 5. Windows 启动器加固（服务"打不开"问题的一部分）

**改动**：`scripts/launch_trial.py` 将 server 路径 `resolve()` 后再传给子进程。**根因**：Windows 8.3 短名（如 `C:\Users\ADMINI~1\...`）下，命令行传短名而子进程把 `__file__` 解析成长名，`server.py` 的 cwd 自检断言失败，表现为"启动即退出、浏览器 ERR_CONNECTION_REFUSED"（由 `test_trial_launcher` 复现并修复验证）。

**本机验证**（诊断数据目录，未动真实数据）：

- `test_trial_launcher` 6/6 通过 ✓

**未完成限制**：用户机器（21203、`C:\Users\21203\...`）上的"双击 BAT 起服务"**尚未由用户本人验收**。若用户机上仍失败，请把终端第一条报错和 `--check` 输出发回，按交接包第 5 节顺序排查。本机没有用户的 Python 3.12.5/3.13.14 安装与 repair-wheels 离线包现场。
