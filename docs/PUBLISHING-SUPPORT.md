# 转角：发布与售后试用指南

本轮在原Python/SQLite试用版上实现，支付、退款和结算仍全部模拟。发布与售后是上一批实现；后续已补站内订单/售后提醒、用户主动开启的浏览器提醒和楼栋/自由地点，见[通知与地点指南](NOTIFICATIONS-LOCATIONS.md)。不申请定位权限，微信系统订阅尚未接入。

## 卖家发布和草稿

进入「发布闲置」，一页完成三部分：选择类别与书况、上传正面/侧面/顶部三张不同实拍图、填写价格和公共交付点。其余信息折叠填写；选择已知缺页或缺失附件时须说明。未核对的情况明确标为未知，不默认完好。不设强制4元底价，允许免费转让。

文字修改约2秒后同步服务器，也可点「立即保存」。每次选图立即上传；界面显示真实保存状态。上传完成并保存成功后，关窗、刷新、再次登录或其他设备可从「我的 → 我的草稿」继续。草稿仅本人可见，最多100份，30天后清除草稿文字记录；并不表示同时物理清理所有未引用图片。

网络异常时，本机尽量保存未同步内容；本机缓存不是服务器备份。文件尚未上传完成时不能保证恢复文件本身，下次会提示重新选择。已成功上传的照片随草稿恢复。多窗口或多设备修改发生冲突时，不覆盖新版或丢弃本机修改，可「读取新版」或「另存一份」。读取新版会先提示替换当前本机内容。退出登录清除该账号本机草稿缓存，服务器已保存的草稿保留。

发布失败保留草稿；相同草稿的重复发布请求返回同一商品，不重复生成库存。发布后的商品编辑、主动下架与任意撤回不是本轮新增能力。

## 建立独立客服账号

试用模式无默认客服密码，每人一个独立账号。先在项目目录为运营者建立管理员：

```powershell
python manage_trial.py create-admin
```

按提示输入独立手机号和12—128字符密码；密码不回显。已有普通用户不能借此自动升级为管理员。运营者登录网页，进入「我的 → 客服工作台 → 创建客服账号」，设置客服自己的登录号码、昵称、初始密码，私下交给本人。也可在服务器执行：

```powershell
python manage_trial.py create-support
```

使用了自定义数据目录时，这两条命令都加 `--data 实际数据目录`，确保与运行中的试用服务一致。不要在仓库、群聊或源码中写入真实密码。管理员可以停用客服并撤销其所有登录会话；普通注册不能申请客服角色。

## 客服怎样收到、处理售后和举报

用户从订单「申请售后」或「帮助与售后 → 提交问题」建立工单，选择售后、举报、申诉、咨询等类型。可上传私密证据图片，每次最多6张、每工单最多30张；遮挡无关个人信息。客服从工作台队列查看，按标题/编号、类型、状态筛选，可手动刷新查新单，消息入口另有新工单站内未读提示；每天08:00—20:00由运营者安排真人值守。当前有站内轮询提示和可选浏览器通知，尚无关窗后台推送。

客服认领后回复、补充证据、内部备注、提交复核或退款建议；其他客服不能抢占已认领工单，管理员可以指派/转派给启用的独立客服。关联买卖双方可以看到对外回复和非内部证据，不能看到内部备注或内部证据。工作人员不能审核自己的工单、交易或商品纠纷。

客服负责核实与建议，管理员负责批准/拒绝退款、结束退款工单和信誉处置。真实转账没有接入；页面显示处理结论并不表示真实货款已退回。

## 退货后重新上架

「仅退款」不恢复库存。「退货退款」要求先由买家标记已退回、卖家确认收到实物，再由管理员核实批准模拟退款。双方点击是交接记录，仍需人工核查证据。

退款完成后，卖家在「我的 → 我的发布」查看符合条件的物品，点击「重新上架」，进入预填草稿，核对当前书况和实拍后再次发布。不会自动在售。原订单保留原商品快照与原账务；新商品关联同一件实物，已在售、预留或再次售出时禁止重复上架，历史退货也不能覆盖最新一笔交易的实物去向。

## 信誉规则和申诉

初始100分，低于60分不能发布或重新上架。退款、差评、举报数量本身均不自动扣分。

| 核实事项 | 处理 |
| --- | --- |
| 轻微问题 | 提醒，不扣分 |
| 首次爽约 | 警告；30天内再次核实的独立爽约事件扣5分 |
| 描述遗漏 | 扣5分 |
| 隐瞒缺陷 | 扣15分 |
| 索取订单外补款 | 扣10分 |
| 伪造证据 | 扣20分 |
| 欺诈 | 扣50分，并限制交易、下架在售商品 |

仅管理员可操作，必须关联已核实并结案的相关工单并填写依据，同一用户同一事件不重复处罚；分数限制0—100，审计记录保存实际增减和前后分数。旧的任意加减分接口已停止接受调整，返回明确提示，不影响旧记录查询。

用户从「我的 → 信誉记录/帮助与售后」提交申诉并注明处罚记录ID。管理员根据已结案申诉冲回原处罚，最多冲回一次；欺诈交易限制只有相关欺诈处罚全部撤销后才解除。非欺诈整改后满30天无新增核实违规可申请人工恢复最多5分，每30天一次，不自动恢复。退款审批与信誉判断分别处理。

## 小程序与升级

小程序源码接入点选发布、账号草稿、冲突恢复、我的发布、售后图片、退回确认、退款建议和信誉申诉。独立客服人员管理、转派及高级信誉审批用网页工作台。源码经Node逻辑测试，尚未通过微信开发者工具编译、真机或发布审核。

升级前停止服务，另存原 `var/`、`var-trial/` 或自定义数据目录及完整备份。使用本轮完整试用包覆盖代码，保留原数据目录，再双击 `start-trial.bat`。本轮新增表/列在启动时迁移，不重建账号与订单。不要只替换旧版 `server.py`，本轮还需要新的 `publishing.py`、`operations.py`、网页文件等。

浏览器访问 `http://127.0.0.1:8080`，必要时按Ctrl+F5刷新。终端需要持续运行。公网访问仍需单独部署后端、HTTPS和持久化数据，本轮没有生成公网网址；Windows原生Python和微信真机尚未执行验证。
