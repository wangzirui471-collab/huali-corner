# 转角：订单提醒与公共交付位置

2026-10-16；本轮在现有Python/SQLite试用版上实现，不迁移接口框架，不产生短信或真实支付费用。

## 如何查看新订单

卖家登录后，页头及手机网页底部「消息」显示订单/售后未读红点。打开「消息 → 订单与售后通知」，可查看、刷新、加载更早通知，点击某条直达相关订单或工单。订单跳转后高亮对应卡片。普通聊天仍在下方会话列表，本轮未增加聊天未读数，红点统计的是订单与售后。

新订单、买家模拟付款、取消、卖家确认时间/交付、买家确认交接、确认或自动收货、改约申请/回应、超时取消以及售后工单的新建、回复和处理进度会写入通知。通知与业务状态在同一数据库事务中保存；相同付款等事件重试不重复发送。客服可收到新工单或被指派提示，已认领工单后续材料通知认领人员和管理员。内部备注不向交易参与者推送。

通知保存到账号，不因刷新、退出或重启服务丢失。旧数据升级不批量生成历史通知；升级后的新事件开始记录。每次展示最多50条，支持加载更早记录。标记已读仅作用于当前账号；「全部已读」只处理本次查询快照之前的通知，随后到达的新通知仍未读。已读仅代表用户做了此操作，不代表已接受改约、确认收货或认可售后结论。

网页登录后约每5秒同步一次未读数量，无需一直停在消息页；切换账号、退出后停止旧账号同步并清理页面红点。网络错误会保留服务端消息，恢复网络后继续尝试；不是实时推送或送达承诺。本轮未做跨浏览器窗口的提醒去重，同一账号在多个窗口开启提醒可能重复出现系统提示。

## 浏览器系统提醒

进入消息中心，**主动点击「开启浏览器提醒」**，浏览器才可能询问权限。不会在打开网站或注册时自动申请，也不要求允许后才能使用软件。选择拒绝后，站内通知仍正常；可到浏览器的网站权限设置自行修改。

本机需要支持Notification接口，并使用HTTPS或浏览器认可的本地开发安全上下文。即使权限允许，部分手机仍限制通知构造、后台网页或要求安装到主屏幕。系统提示只显示通用“订单／售后有更新”，不在锁屏暴露手机号、详细地点、售后正文或证据。点击提示进入消息中心，本轮不包含推送订阅服务或Service Worker。

**网页关闭、设备休眠、后台被冻结或断网时，不保证弹窗。** 开启本机提醒的选择按账号保存在当前浏览器，其他设备需要自行开启；「关闭本机浏览器提醒」保留站内消息。退出账号会关闭本页面创建的系统提示。

## 微信小程序

小程序源码接入账号站内通知、首页/消息未读数、已读、订单/工单跳转与分页。小程序在前台使用期间约5秒同步，进入后台停止计时，返回前台再同步；不是微信聊天列表中的服务通知。

微信系统订阅消息**尚未接入**：还需要真实AppID、获批订阅模板、用户授权、服务端发送接口/凭据配置和送达验证。本版只提供说明入口，不弹一个没有发送能力的授权框，不声称关闭小程序也能收到。尚未进行微信开发者工具编译、真机、平台审核或线上发送验证。

## 楼栋与自由填写

网页和小程序的发布、送货下单、改约都提供楼栋选择，并保留可编辑公共地点输入框。选择楼栋会填入“楼栋＋楼下公共入口”，可改成实际公共见面点；不在列表里时直接输入即可，不需要申请定位权限。已有自提地点保持不变，不能通过修改订单外的表单偷偷改变已下订单的快照；改约须由另一方接受。

新增本科截图候选：C1、C2、C3、C4、B9、B4、B3、B2、D1、C8、C7、C6、C5。原有A/L/G/D楼栋仍保留。列表来源是用户截图，不代表学校已核实的完整目录。地点用于公共交接，无需填写宿舍房号、身份证或私人住址。商品发布地点可公开展示；订单收货地点不在通知和公开主页暴露。

本轮没有新增常用地址簿、GPS定位、校外地图或送货距离计价。书籍仍逐本定价，合并送货费与订单总价规则沿用已有实现。

## 更新和验证

使用本轮完整试用ZIP，不能只替换server.py：需要notifications.py、locations.py及新增网页文件。停止旧服务，另存备份，更新代码时保留原var/、var-trial/或自定义数据目录，再双击start-trial.bat。浏览器可按Ctrl+F5刷新旧文件。账号、旧订单、照片和原账务保留，通知表在启动时增量创建。

验证：90项Python测试、7个Node客户端脚本、真实Chromium消息/权限触发/地址及原发布、试用交易、售后流程。模拟Windows MIME兼容与375/390/768/1440响应式、只读静态演示也有回归。实际Windows原机、微信真机、操作系统通知送达及公网部署均未验证。本地地址和GitHub源码不等于已上线网站。
