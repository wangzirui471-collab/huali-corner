## 3. 架构：一套代码，三个运行环境

| 环境 | 入口 | 数据 |
| --- | --- | --- |
| 本地 Python | `Backend mission/server.py` | SQLite（默认）/ MySQL（`HC_DB`） |
| Cloudflare Worker | `worker.py` → `app/cloudflare/` | D1 + R2 + Assets |
| 本地 AI 服务 | `ai_service/server.py`（127.0.0.1:8093） | `ai_service/index.json` 知识库索引 |

Cloudflare 运行时（Pyodide）硬限制：**没有线程、没有持久化 sqlite3、没有 `hashlib.pbkdf2_hmac`**；密码 PBKDF2 600000 轮放浏览器端，服务端只存摘要。WebCrypto PBKDF2 生产上限 10 万轮。

## 4. 数据库三套

- SQLite：删除日志模式（**不用 WAL**，否则最后连接关闭 checkpoint 会抢写）；写事务用 `_WRITE` RLock 串行化（防超卖）。
- MySQL：`HC_DB=mysql://...` 选开；连接必须 `autocommit=True`，否则读连接快照看不到刚提交的行。
- D1：30 张表，`batch()` 是唯一事务原语；`guarded_batch` 做「守卫 SELECT + 写入」。

三处 schema 要同步：`app/core/database.py`（SQLite + MySQL）、`app/cloudflare/schema.sql`（D1）。
**教训：schema.sql 加了表，必须单独在 D1 执行一次 CREATE（`wrangler d1 execute ... --remote --command "CREATE TABLE ..."`），否则线上 500。**

## 7. AI 客服（本次重点，详见 `docs/AI-SUPPORT.md`）

- **模型**：DeepSeek 官方 `deepseek-flash`（V4.1-Flash，最便宜档），接口 `https://api.deepseek.com/chat/completions`。
- **链路**：客服页宠物 / 工单页「AI 建议回复」→ 本地 `/api/ai/chat` 或 `/api/ai/reply` → 检索知识库 → DeepSeek → 只依据资料回答；资料不足/投诉/要求人工 → 固定兜底话术转人工。
- **不做自动发送**：AI 只生成草稿，客服确认后插入回复框。
- **权限矩阵**（`AI_PERMISSIONS`，前后端同一口径）：

| 能力 | 用户 | 客服 | 管理员 | 开发者 |
| --- | --- | --- | --- | --- |
| 客服页 AI 宠物提问 | ✅ | ✅ | ✅ | ✅ |
| 工单页 AI 建议回复 | ❌ | ✅ | ✅ | ✅ |
| 查看全部用量 | ❌ | ❌ | ✅ | ✅ |
| 开关/额度 | ❌ | ❌ | ✅ | ✅ |
| 重载知识库（本地） | ❌ | ❌ | ✅ | ✅ |
| 改模型/接口/Key | ❌ | ❌ | ❌ | ✅ |

- **配置**：管理员工作台 → AI 客服；表 `ai_settings`（开关 + 普通 30 次/天、客服 100 次/天）+ `ai_usage`（配额，两次至少间隔 2 秒）。
- **知识库**：`ai_service/knowledge/faq.md` 为主；改完跑 `python ai_service/ingest.py`，再重新生成 `app/cloudflare/ai_knowledge.py` 并部署。
- **启动本地 AI 服务**：
  ```powershell

  cd "E:\zi\huali-corner-trial"
  python ai_service\server.py
  ```
- **隐私**：问题会发送到 DeepSeek；内部备注不发送；日志只记元数据（`var-trial/ai-usage.jsonl` + `ai_usage` 表）。

## 8. 必读规则与踩过的坑

1. **路径只从 `app/core/config.py` 取**（`ROOT`/`WEB`/`ASSETS`/`data_dir(trial)`），不要 `Path(__file__).parent/...`。
2. **全局状态只在 `src/core/state.js`**；`router.js` 与 `pages/*` 不许互相 import（用 `core/nav.js` 的 `render/go`）。
3. **本地 Ollama/AI 请求必须绕过系统代理**（否则 127.0.0.1 也被代理成 502）：`urllib.request.build_opener(ProxyHandler({}))`。
4. **AI 的 click handler 必须放 `actions/*.js` 的 `clicks`，不能放 `submits`**（否则点击不触发）；对象里补逗号。
5. **工作区可能有并行会话改动**：提交只 `git add` 自己的文件，部署用干净 worktree。
6. **系统 Python 3.8 跑不了并行重构后的代码**（用了 `int | None`），跑测试用 `.venv-trial`。
7. **Windows 上 `nul` 是保留设备名**，普通删除会失败，用 `.git/info/exclude` 忽略即可。
8. 前端事件全部走 `actions/index.js` 的 `clicks`/`submits` 分发；新增交互在对应模块里加 handler。
9. 金额整数分；时间秒级时间戳；角色/状态用固定机器值。
10. 演示 `var/` 与试用 `var-trial/` 不混用；`var-trial/` 严禁删除。
