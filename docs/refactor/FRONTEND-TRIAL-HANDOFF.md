## 3. 构建与预览

需要 Node.js 22.12+（本机实际使用应用自带 Node 24.19.0）。不要使用这台电脑 PATH 中的 Node 18.20.4；不要复制本机 `node_modules` 或 Python 虚拟环境。

在项目根目录：

```powershell
node --version
npm --prefix apps/web ci
npm --prefix apps/web run lint
npm --prefix apps/web run typecheck
npm --prefix apps/web run test:unit
npm --prefix apps/web run build:trial
npm --prefix apps/web run preview:trial
```

预览打开 `http://127.0.0.1:4173`。开发模式用 `npm --prefix apps/web run dev`，地址 `http://127.0.0.1:5173`。深链回退由 Vite 提供，不要用旧静态服务直接打开 `/products/123` 来替代 SPA 预览。不要双击 `index.html`。

| 构建 | 用途 |
| --- | --- |
| `build` → `dist` | 默认生产入口仍显示未上线；没有开放业务页或开发样板 |
| `build:preview` → `dist` | 仅组件样板，供原工程验收 |
| `build:trial` → `dist-trial` | 本轮业务页面候选，不包含组件样板入口；只用于隔离联调 |

`dist-trial` 已被 Git、ESLint、Prettier 排除。`Check` 任务增加 trial 构建，CI 配置尚未推送/执行本轮改动。

开发与 preview 的 `/api`、`/media` 默认代理 `http://127.0.0.1:8081`；`/api/v1` 继续指向本机 8001。可用终端临时变量 `HUALI_LEGACY_ORIGIN` 改成其他**本机 HTTP 端口**，远程主机、账号密码、路径、query、fragment 配置会被拒绝。代理保留 Host，不伪造 Origin；旧服务继续检查同源写入。

## 4. 另一台电脑的隔离旧服务

使用全新合成数据目录，不复用已有试用目录，不连接真实 MySQL。下面只修改当前终端变量、项目虚拟环境和项目忽略目录，不安装 Docker/WSL 或全局 Python 包。

```powershell
if (!(Test-Path .venv-trial/Scripts/python.exe)) { python -m venv .venv-trial }
& .venv-trial/Scripts/python.exe -m pip --isolated install -r 'Backend mission/requirements.txt'
```

另开终端启动旧服务，先确认端口 8081 未被其他项目占用：

```powershell
# 只清本终端的数据库选择和预设账号，不修改系统环境变量。
$env:HC_DB = ''
$env:HUALI_ADMIN_PHONE = ''
$env:HUALI_ADMIN_PASSWORD = ''
$testData = Join-Path (Get-Location) ('artifacts/web-acceptance-' + (Get-Date -Format 'yyyyMMdd-HHmmss'))
& .venv-trial/Scripts/python.exe 'Backend mission/server.py' --trial --host 127.0.0.1 --port 8081 --data $testData --public-origin http://127.0.0.1:4173
```

本机未执行上面的业务服务启动与浏览器联调；这是交给测试电脑的操作步骤。原旧服务会在合成目录生成随机初始管理员凭据，并运行其原有定时任务/本地备份。凭据在该目录私下核对，不复制进测试报告或 Git。用合成普通账号覆盖买家、卖家和客服场景。

业务测试不需要新 FastAPI 8001。正式 API 仍锁 Pillow 12.3.0；不要将 Worker 探针 12.2.0 用于真实上传。不要使用旧 `remote:true` 配置验证本包。
