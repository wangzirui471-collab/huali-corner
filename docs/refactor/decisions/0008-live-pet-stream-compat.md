# 0008：保留线上AI的Web宠物与流式兼容切片

状态：本轮已实施并发布。日期：2026-10-25。

## 依据和范围

用户明确要求把已交付Vue前端同步原网址、保留AI，随后选择网站宠物互动、可拖动对话窗、流式回答。参考仓库只在线阅读README，不下载、安装或复制代码/素材。此授权允许本轮发布，不包含迁移真实数据库、开通收费资源或真实账号写测试。前轮公开FAQ、FastAPI端口架构和未完成阶段门槛继续保留。

实际线上AI比本地两个旧工作区更新。权威基础是Worker版本 `5e7bd074-0fe4-42ba-887a-2f5347a7479e` 的218个原字节模块，包含既有办公、工作、发布辅助、角色、知识、安全防泄漏和账号偏好。不能拿旧AI工作区或原c92567d后端替换它。

## 决定

- `apps/web` 保持JavaScript/Vue/Element Plus、当前品牌与已落地布局。宠物代码归 `features/support/pet`，全局布局只按构建开关懒加载入口。线上trial构建显式设置 `VITE_HUALI_COMPAT_API=0`、`VITE_HUALI_ASSISTANT_MODE=legacy-stream`，同源旧 `/api` 仍是唯一业务writer；本机FastAPI的公开FAQ默认路径没有被替换或宣称已迁移上线。
- 新 `POST /api/ai/chat/stream` 是原Worker AI调度的薄兼容适配。只修改原入口和 `call_api`/计数钩子，新增两个流模块，其他216模块原字节保留。ContextVar使流hook局限于当前请求；原 `/api/ai/chat`、原规则/知识/权限/完整回答DTO继续原实现。没有新交易写规则、迁库或散落供应商SDK。
- 新SSE入口复用原会话核实、AI开关与额度。白名单正文只有问题、最多四条历史与UUID；Bearer只送本站认证头。供应商读取 `stream:true` 的真实增量，客户端只以done作为成功，取消/断流保留输入及未完成文本、不自动重试、不自动建工单。
- 增量过滤保留原思考隐藏和提示词指纹保护；可疑前缀暂缓显示，最终正文及元数据仍以原完整DTO为准。用户正文按纯文本渲染，不执行模型HTML或任意链接。
- 原宠物偏好接口是唯一偏好writer；读取失败不以默认值覆盖旧自定义形象。现有自定义形象、life字段和角色配置保留。高级办公/工作/设置及旧发布辅助暂由 `/legacy-ai.html#home` 完整原版入口保留，不能宣称已全部迁为Vue组件。
- 模型开始前在原额度体系预留一次，成功不双扣，已开始的失败/取消保留次数；纯规则答不扣。UUID仅关联轮次，没有跨实例持久幂等和原子并发配额保证，显式重试可能再次调用模型。不得把这个切片描述为账务/幂等迁移完成。
