# 0002 数据权威源未确认时的兼容边界

日期：2026-10-21。状态：实施约束。

## 输入

用户确认目前尚不确定正在接收用户写入的数据库，并要求在可行范围内保持兼容与扩展性。

## 决定

在只读盘点完成前，保留旧 Web、原生小程序及 SQLite/MySQL/现有 D1 运行路径；不删除历史账号、订单、媒体或接口，也不把空库绑定成线上权威。新增规则先放入纯规则或单一应用用例，再由明确适配层供旧/新协议使用；不长期复制本地与 Worker 两套可独立演进的业务逻辑。

数据访问通过窄接口承载业务所需的读取和原子命令，不为所有表建立泛型仓储。D1 作为目标落点，但现有真实数据来源需核对部署版本、schema、表计数和备份后确认。迁移按扩展、回填、对账、单一写入口切换执行；任何未迁移客户端由版本化兼容接口承接。

## 影响

离线重构、合成测试、组件和协议工作继续。生产数据迁移、旧写路径退役及发布切换暂不执行。确认权威写源后再确定具体导出映射和回滚窗口；“可兼容”不能解释为让旧新交易 writer 随机写同一库。
