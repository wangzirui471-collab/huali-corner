# 华立转角计算机学院试点 Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans inline. User explicitly requested making the software now; continue within the approved local simulation scope.

**Goal:** Deliver a working campus marketplace, community and support prototype with simulated payment and computer-college pilot.
**Architecture:** Python standard-library HTTP API + SQLite transactions + browser UI + native WeChat client sharing the API. Real SMS, identity services and payment remain disabled. Standard-library backend replaces proposed Next.js to avoid dependency/runtime cost in the available environment; no existing application is overwritten.
**Tech Stack:** Python 3.12, SQLite, vanilla JavaScript/CSS, Pillow for upload decoding (already installed), unittest, Playwright (already installed).
**Spec:** ../specs/2026-10-15-huali-corner-unified-design.md plus current user instruction.

## Global Constraints
- Guangzhou pilot; canonical college 计算机工程学院; anyone with verified phone may register, alumni supported.
- Three photo angles; one book per listing; book condition checkboxes; copyright/inner-page photos optional and clearly indicated.
- Combined pickup for same seller; delivery fee once per combined order using maximum constituent listing delivery fee, disclosed before payment.
- Credit starts at 100; below 60 cannot publish; no automatic score penalty on report, staff reason/audit and appeal required.
- Local simulated phone verification and funds only. Bind localhost, no public deployment or purchase.
- Chat, favorites, likes, sharing, community groups and support 08:00–20:00 included.

## Review Focus
- Cross-account leakage: private messages, addresses, tickets and media.
- Money races: duplicate checkout/payment/refund/settlement; receipt/dispute ordering.
- Fake uploads: duplicates, missing angles, non-image and unsupported ownership.
- Credit abuse: reporting cannot punish, admin cannot adjudicate own transaction.
- Group capacity: concurrent join, duplicate membership and total-channel behavior.
