# 校园商城首页前端优化 Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement inline.

**Goal:** 保留所有业务功能，改为搜索优先、单轮播、分类、快捷入口、标准商品流的校园首页。

**Architecture:** 沿用原生 ES modules、hash 路由及现有 API。页面负责模板，actions 负责轮播和分页生命周期；共享生命周期句柄放 state。使用独立、带作用域的首页样式，不迁移框架或数据库。

**Tech Stack:** HTML/CSS/JavaScript、Node test runner、Playwright Chrome。

**Spec:** 用户 2026-10-21 六张参考图及本轮已批准设计。

## Global Constraints

- 暖黄品牌，克制暖红价格，白底留白；支持 PC 与移动端及减少动效偏好。
- 不改后端、权限、数据、支付、会话；保留逛逛/社区/论坛/我的及搜索、发布、求购等功能。
- 公共商品卡片不含下架操作；我的商品及工作台保留管理能力。
- 三端交付使用同一提交；只提交本任务文件，不覆盖真实数据。

## Review Focus

- 快速切页或换账号：旧请求不得覆盖新页面。
- 重复观察通知：只请求一页，追加去重。
- 加载失败：保留已有列表与滚动位置，手动重试同一页。
- 免费货架与收藏：保留原来的完整筛选语义。
- 小屏与键盘：不横向溢出，轮播暂停和切换可操作。
