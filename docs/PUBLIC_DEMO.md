# 华立转角公开演示版

用户确认的范围：先给同学一个链接看效果，使用独立演示数据，不收集真实手机号或收货地址。此版本是静态网页，不运行交易后端。原来的 Python 本地模拟版保留。

## 一次上传，生成分享链接

1. 下载仓库里的 `artifacts/huali-corner-public-demo.zip`，解压。
2. 打开解压后的 `huali-corner-public-demo` 文件夹，确认直接能看到 `index.html`、`src` 文件夹、`demo-data.json` 和 `assets` 文件夹。前端已拆成 ES 模块，所以必须有 `src` 这一整层，只拷 `index.html` 会白屏。
3. 在浏览器打开 <https://app.netlify.com/drop>，按页面提示注册或登录托管账号。
4. 把第2步的整个文件夹拖入上传区域，等待部署完成。不要上传整个 Python 项目，也不要上传 `var` 或学生表格。
5. 在部署完成的页面打开平台实际生成的 HTTPS 网址，先用手机浏览器确认首页和商品详情可以打开，再把该网址发给同学。不能把 localhost、Netlify 管理后台地址或 ZIP 下载地址当成网站分享。

静态托管不依赖个人电脑持续开机。不必为了演示先购买服务器或域名；可先使用平台提供的免费额度和二级域名，额度、账号要求和规则以托管平台当时说明为准。不要在此步骤开通付费套餐。

本次没有可用的托管平台登录凭据，未代建托管账号、未提交线上部署，也没有生成或验证公网网址。GitHub 上传成功与网站上线是两个独立状态。文件包准备和本地浏览器验证已完成；真正发布需上述托管平台操作。

## 演示边界

- 可浏览首页、搜索、分类、价格排序、商品详情、卖家公开主页和两条社区样例，商品链接可分享。
- 演示商品和图片明确标注为虚构或AI示意，不代表真实出售、实拍或真实成交信誉。
- 不提供手机号输入、注册、上传、收货地址输入、发帖、私聊、真实交易或客服操作。点击对应按钮展示功能说明，不提交数据。
- 不包含真实数据库、登录令牌、演示手机号、付款密钥或上传图片；没有账户或管理员登录接口。
- 没有应用层统计脚本、广告或第三方素材请求。静态托管提供商仍可能按其隐私政策记录访问日志，例如IP、请求路径和浏览器信息；“不收集”指本演示不提供上述个人资料填写或提交功能。
- 此包没有交易后端；不能通过移除前端限制获得订单、聊天或客服数据。将本地 `server.py` 暴露公网是另一件事，不能用本演示的验证结果证明其安全。
- 安全响应头模板 `_headers` 适用于支持该格式的静态托管平台。其他平台应设置同等响应头；核心隐私隔离来自包内不存在后台与私人数据。

## 重新生成

在项目根目录，安装原有 Python 依赖后执行：

```bash
python3 scripts/build_public_demo.py --output dist/public-demo
```

输出目录必须不存在或为空，脚本拒绝覆盖非空目录。脚本只创建全新的临时数据库，不接受已有数据目录。临时数据库用完删除，只复制固定清单内的静态资源及虚构数据。可用普通静态HTTP服务检查，直接双击 HTML 打开不受支持。

```bash
node --check "web 7M/public-demo.js"
python3 tests/public_demo_smoke.py
python3 tests/browser_smoke.py
python3 tests/ui_redesign_smoke.py
```

静态浏览器验证单独使用普通文件服务器，从子目录提供导出网页，不启动 Python 应用；检查搜索、商品、主页、社区、受限页面、375/390/768/1440宽度，以及没有 `/api/` 请求和写入请求。原有浏览器交易验证确认本地模拟版继续可用。
